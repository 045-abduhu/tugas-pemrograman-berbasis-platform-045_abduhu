# Paket Tugas Pertemuan 3

Paket ini berisi draft jawaban Tugas Pendahuluan dan lima Tugas Mandiri Pertemuan 3.

## Struktur
```text
pertemuan-03/
├── README.md
├── tugas-pendahuluan.md
└── tugas-mandiri/
    ├── frontend/web/
    │   ├── tugas-mandiri-1-component.html
    │   ├── tugas-mandiri-1-utility.html
    │   ├── tugas-mandiri-1-css-compare.md
    │   ├── tugas-mandiri-2-layout.html
    │   └── tugas-mandiri-2-layout.md
    └── backend/
        ├── tugas-mandiri-3-auth-matrix.md
        ├── tugas-mandiri-4-jwt.md
        └── tugas-mandiri-5-secret-hygiene.md
```

## Cara menggunakan
1. Ekstrak ZIP.
2. Salin folder `pertemuan-03` ke repository tugas individu (Repository A).
3. Sesuaikan identitas, proyek, dan jawaban agar sesuai dengan pengamatan serta proyek kelompok sendiri.
4. Buka HTML dengan browser. Halaman Tailwind memerlukan internet untuk memuat CDN.
5. Ambil screenshot nyata dari laptop dan ukuran viewport 360 px. Simpan di folder tugas yang sesuai atau tempelkan ke laporan Markdown.
6. Untuk Tugas Mandiri 4 dan 5, jalankan pengujian pada API praktikum sendiri. Jangan menulis hasil pengujian seolah-olah sudah dilakukan bila belum.
7. Jangan mengunggah file `.env`, password, JWT_SECRET, atau token JWT lengkap ke GitHub/laporan.

## Catatan penting
- Nama, NIM, waktu pengerjaan, hasil HTTP aktual, dan screenshot harus disesuaikan dengan hasilmu sendiri.
- File ini merupakan paket awal yang dapat diedit, bukan bukti bahwa pengujian sudah dijalankan.
- Tugas Pendahuluan mengacu pada instruksi Pertemuan 3. Untuk Tugas Mandiri 5, modul menekankan pemeriksaan agar `.env` tidak dilacak Git dan token lengkap tidak tersimpan dalam laporan/kode client.
